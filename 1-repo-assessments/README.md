## Selection guidance

Lead with Azure Monitor for current technical depth, Azure AI for launch execution, and System Center for career continuity. Use Azure Compute as a supporting example of documentation governance rather than as the primary portfolio story.

## Access note

The connected GitHub account authenticates as `bandersmsft`. Public fork content is readable through the connector. Some organization-owned API endpoints return a Microsoft SAML enforcement error, so this assessment uses public fork links, public commit links, and existing local evidence where direct organization metadata is unavailable.
