# Azure AI documentation case study

## Portfolio summary

I created and updated customer-facing documentation for Azure AI Video Indexer Live Analysis as a public preview feature. The work covered the feature overview, Azure Arc extension deployment, camera management, AI insights, areas of interest, event summaries, recordings, and troubleshooting.

## What this demonstrates

- I learned a new product area quickly enough to document a multi-part feature launch.
- I connected conceptual, deployment, configuration, and troubleshooting content into a usable customer path.
- I coordinated substantial updates across existing product overview and troubleshooting articles while adding new feature content.
- I supported a release that required precise terminology, navigation updates, and practical portal guidance.
