## Preservation rules

1. Prefer a personal public fork when one exists and has been verified.
2. Label Microsoft-owned pull request and commit links as historical or externally controlled.
3. Keep the original Microsoft repository name and URL intact when it identifies the source of a contribution.
4. Recheck personal fork branches and author-history URLs before sending the portfolio to a recruiter.
