## Fragile links

- MicrosoftDocs repository pages, commit filters, and pull request URLs depend on Microsoft retaining public repositories and public history.
- Microsoft Learn pages are live published evidence, but Microsoft controls their paths, content, and availability.
- Microsoft-owned pull request repositories, including `*-pr` repositories, are especially fragile because they are commonly private or organization-controlled.
- Local Work IQ and exported CSV files are private corroboration. They are not suitable as recruiter-facing links.

## System Center preservation status

System Center preservation is practical through an authorized GitHub fork or a local clone that retains all refs. The current connector did not expose fork or repository-creation operations, so this task did not create a personal copy and did not alter the Microsoft-owned repository.

## Recommended maintenance

1. Keep the personal GitHub account and the `banders@microsoft.com` commit-attribution email intact.
2. Keep the personal forks public unless you intentionally choose a different preservation strategy.
3. Periodically verify the personal fork default branches and author-filtered commit URLs.
4. Preserve a local clone of SystemCenterDocs and other high-value Microsoft-controlled repositories when authorized.
5. Recheck live Learn links before sending the portfolio to a recruiter.
