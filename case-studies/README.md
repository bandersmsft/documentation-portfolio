## How to read the evidence

Every case study separates three things on purpose.

**Public evidence** is anything an outside reader can verify without an account, mainly commit history in Microsoft public documentation repositories and published documentation on Microsoft Learn.

**Professional background** is work the record supports internally but that cannot be linked publicly, including work-item records, monthly delivery reports, and internal tooling. Microsoft owns that material and I did not retain it.

**Boundaries** state what the evidence does not establish. They are in every case study because a portfolio that only claims upward is not usable for hiring decisions.
