## Measurement notes

- The nine-repository public commit audit totals 4,289 commits. It covers `azure-docs`, `azure-monitor-docs`, `SystemCenterDocs`, `entra-docs`, `azure-compute-docs`, `dataexplorer-docs`, `azure-ai-docs`, `azure-security-docs`, and `SupportArticles-docs`.
- The exported pull request history contains 2,292 merged pull requests across more repositories than the public commit audit.
- A personal fork preserves the repository snapshot and imported Git history, but it does not make Microsoft-owned pull request URLs durable.
