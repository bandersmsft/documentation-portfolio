# Azure Compute documentation case study

## Portfolio summary

I helped maintain documentation boundaries between Azure Monitor and Azure Compute by identifying articles with incorrect ownership metadata and routing them to the appropriate product area. The work focused on information architecture, metadata accuracy, and maintainable ownership rather than broad prose revision.

## What this demonstrates

- I can audit a large documentation surface for ownership and metadata drift.
- I understand that accurate product classification improves reviewer routing, discoverability, and long-term maintenance.
- I can coordinate changes across repositories while keeping edits narrow and traceable.
